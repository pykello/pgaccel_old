The [histogram path](Q13-DESIGN.md) counts filtered fact matches through
verified dimension keys and includes zero-match dimensions in frequency
bins. Ordered literal filtering uses bounded SIMD byte probes followed
by exact comparisons and the existing RE2 fallback for surviving non-ASCII
candidates. Duplicate dimension keys retain general execution.

The frozen binary passes all 200 native tests, five focused sanitizer
tests and all 22 SF1 answer comparisons. [Iteration history](Q13-ITERATIONS.md)
preserves the old executor, regex, byte-search and SIMD measurements.

An earlier 13-trial comparison was rejected by the trial-count gate
and retained as q13-confirm13. The results above use the required 15
SF10 trials and nine SF100 trials. Interrupted baseline files are excluded.

PGAccel scans resident native columns; DuckDB uses its persistent database;
ClickHouse uses MergeTree. These engineering measurements are not audited
TPC results. Q13 uses original SQL without a floating-point adapter.
