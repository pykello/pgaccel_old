The [shared-total path](Q15-DESIGN.md) aggregates a bounded integer key
domain in independent worker arrays, merges exact totals, and finds the
extremum once. The scalar and join must reference the same grouped source.
Every tied group survives; dimension filters apply after the extremum.
Duplicate dimension keys and unsupported inputs retain general execution.

The frozen binary passes all 193 native tests, eight focused ASan/UBSan
tests and all 22 SF1 answer comparisons. [Iteration history](Q15-ITERATIONS.md)
preserves the original materialized execution measurement and every trial.

PGAccel scans resident native columns; DuckDB uses its persistent database;
ClickHouse uses MergeTree. These engineering measurements are not audited
TPC results. Q15 uses original SQL without a floating-point adapter.
