at both scales; subsequent working-tree changes are not in this runner.

The [filtered arithmetic path](Q6-ITERATIONS.md) evaluates selected row
blocks with the existing stripe arithmetic program. Bounds prove every
intermediate and reduction subset fits int64 before SIMD reduction;
unsupported or wider cases retain checked 128-bit interpretation.

The frozen binary passed all 176 native tests and six focused ASan/UBSan
tests. [Q6.json](Q6.json) retains every trial, settings and binary hashes.
Raw answers and resource samples are stored beside the external report.

PGAccel scans resident native columns; DuckDB uses its persistent database;
ClickHouse uses MergeTree with column statistics. These are engineering
measurements on the same generated data, not audited TPC results. Q6 uses
the original SQL without a ClickHouse floating-point adapter.
